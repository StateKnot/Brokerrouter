# M4.3a：持久输出隔离转存

更新：2026-09-13。契约 `private-output-quarantine-v1`。实现生成前存储容量准入、供应商产物到私有 S3 的持久分块转存、来源校验、恢复与取消清理。它是 M4.3 的隔离存储子包，**不是输出审核或最终交付**；视频/图片/3D 二进制审核、真人审阅入口及批准后下载在 M4.3b，仍未开放。

## 独立权限与升级顺序

输出 worker 使用独立登录身份，仅加入 `brokerrouter_media_outputs` 权限组，不得加入 `brokerrouter_runtime`、operator、reconciler 或真人控制组。它可以处理输出资产、清理来源密文和记录存储审计，不能修改人民币账本、发起模型生成或批准用户操作。

资产表和分块表启用 PostgreSQL RLS：输入服务 `brokerrouter_assets` 只能看到 input；输出 worker 只能看到 output。两个用途角色互不继承，输出身份不能通过 `SET ROLE` 切为输入或模型执行身份。规则同时作用于查询与写入，防止混合版本部署时旧资产服务忽略 kind、通过旧下载路径读取输出。迁移账户/表拥有者/超级用户可绕过 RLS，不能用于服务进程；不同用途的登录账户不得混合角色。RLS 用于服务用途隔离，HTTP 的 tenant + key 精确授权仍不可省略。

升级流程：先停新任务准入/摘除资产服务流量 → 备份并应用 0008 → 以部署身份重新应用 `deploy/permissions.sql` → 验证专用登录角色和 RLS → 部署新媒体/输入资产服务及 output worker → 发布带输出合同的新端点 → 再恢复准入。迁移启用 RLS 而权限策略尚未安装时，受限服务会失败关闭，不可临时使用超级用户恢复流量。

```sh
# Secret 注入 DATABASE_URL，连接专用 brokerrouter_media_outputs 登录身份。
brokerrouter output-worker --concurrency 2
```

并发可配置 1–8，默认 2；SIGTERM 停止领取新工作并排空当前工作，worker 意外退出会使进程失败退出，交给部署监督器重启。数据库版本/checksum 不匹配拒绝启动。存储变量和加密配置沿用 [M4.1](m4-assets-pricing.md)，来源解密 keyring 还须包含生成服务使用的结果密钥版本。输出服务不加载模型供应商 API 凭据；S3 只授予私有对象 Get/Put/Delete，禁止公开 ACL 和匿名访问。

## 不可变输出合同与容量

新媒体端点必须额外发布以下字段，不能由请求调用方指定：

```json
{
  "maximum_output_bytes": 134217728,
  "output_origins": ["https://provider-output.example"]
}
```

上面是占位域名，不是某供应商的实际地址。需要用该区域/固定模型实际返回的来源填写，并完成 LIVE-11。origin 是 scheme + host + port 的精确集合（1–16 项），不接受域名后缀/通配符、用户名密码、路径、查询或 fragment。生产只允许 HTTPS；HTTP/私网仅在明确设置 `allow_private=true` 的隔离 fixture/受信私网配置中使用。

每作业最大输出 1 字节–512 MiB，由端点显式配置。创建作业时，在同一 PostgreSQL 事务中预留模型人民币预算和 tenant/key 两层资产字节容量；任一不足则作业、账本和容量全部回滚，不会发起生成。字节容量与人民币金额是独立口径，不能当作模型成本。

端点版本及容量上限冻结在原请求中。收到来源的有效 Content-Length 后，事务将容量预留转换为实际资产占用、释放差额并创建输出资产清单；不会因为存储配额不足才在生成后临时超配额。失败/取消/期限耗尽释放字节容量，但不冲销已经发生的模型费用。

旧 M4.2 端点/请求快照仍能解码与查询已付费任务；没有输出合同的端点不参与新任务路由或媒体能力列表。旧作业没有容量准入记录，保持原有隔离边界，不自动转存、放行或重新付费生成。迁移不篡改旧路由快照；需要输出能力时发布完整的新端点版本。

## 来源、分块和恢复

只读取服务端从原生成响应取得的加密 URL，没有用户 URL 导入接口。下载时再次核对冻结的 origin 集合、解析并固定 DNS 地址、检查网络边界；禁止代理、重定向、隐式 HTTP 重试。不会向产物源发送模型 API Key、Cookie 或 Referer。

仅接收 200 完整、无内容编码的响应；必须有受容量上限约束的 Content-Length 和强 ETag。弱 ETag、缺失长度、206、重定向或压缩内容不降级处理。根据 [RFC 9110 的 If-Match 强比较语义](https://www.rfc-editor.org/rfc/rfc9110.html#name-if-match)，后续恢复携带原 If-Match，同时核对返回的原 ETag、长度和 URL 哈希；源站不遵守条件请求的行为必须在供应商认证中排除。

固定 4 MiB 分块，复用 AES-GCM、每块 SHA-256、不可变对象键和 S3 条件写。每块先登记，再写密文；对象已写但 DB 未确认时，恢复读旧密文并验证，绝不覆盖。完成时从私有存储重新读取全部块，计算整个文件 SHA-256。文件字节不落数据库或本地明文临时文件。

恢复目前从头 GET **同一原文件**，复用并核对已登记分块，不是 HTTP Range 续传，不会拼接不同来源版本。ETag/长度/已写块不一致则终止并隔离清理；存储/网络临时错误仅重试 GET/不可变块操作，不重发生成 POST。HTTP GET 本身可能产生源站流量成本，不包含在模型人民币账本中，需单独运维监控。

网络 I/O 不持数据库锁。持久 UUID 租约 660 秒，每次拷贝全流程上限 600 秒，HTTP 总时限 300 秒，失败后的下一次尝试间隔 15 秒。写块、完整性确认和隔离状态提交都重新校验当前租约；旧 worker 不得发布。资产已经完整落库而最终隔离事务失败时，恢复直接采用已完成的不可变资产，不再次访问已过期来源。

## 状态、取消和保留期限

| 输出存储状态 | 含义 |
| --- | --- |
| pending | 已预留容量，等待生成成功/可取来源 |
| copying | 已冻结来源版本与清单，正在加密转存 |
| quarantined | 完整性已校验，仍未经内容审核、未授权交付 |
| failed | 来源合同/一致性不满足，容量释放，模型费用不变 |
| cancelled / expired | 生成关闭、取消、权限/turn 结束或期限耗尽；不自动重新开放 |

媒体 API 的 `output_storage` 只显示状态、大小、错误类别与 `content_safety=not_evaluated`；作业仍为 `output_pending`、`artifacts=[]`、`delivery=not_released`。现有 input metadata/content/chunk/complete/PUT/DELETE 路径一律不能作为输出访问入口。预签名供应商 URL 不返回客户端；成功隔离后立即清除来源密文。

输出容量/资产保留期限从原作业创建起 24 小时；来源密文仍保留生成成功后最多 1 小时，未完成转存时受此更短期限限制。取消、Key/用户/Runtime 撤销、turn 关闭/过期会停止后续输出写入与保留，不撤销已有模型费用。已经发生的 HTTP 网络字节无法收回，但迟到响应不能使资产重新可用。

逻辑关闭、容量释放与存储审计在同一事务中。物理对象清理沿用持久 GC 游标、至少 2 分钟延迟和后续复核；转存过程中取消后的迟到 S3 PUT 也不会复活资产。对象版本/供应商备份是否真正销毁仍是生产存储认证内容。

生产必须对 output worker 停止、source 期限接近、pending/copying 积压、配额占用、失败、GC 和对象存储容量告警。超过来源期限后，系统宁可报告无法交付，也不重新发起收费生成。1 小时来源恢复窗口、24 小时保留、最大对象和吞吐量必须在部署认证时验收，不是已承诺的生产 SLO。

## 验证与后续

新增 12 项测试覆盖实际 HTTP、原子资金/容量、全部旧资产 API 绕过路径、密文与全文件哈希、对象写后 DB 故障、最终事务失败、源版本变化、取消/过期/turn 关闭、旧租约竞争、最小角色/RLS、精确 origin 和真实本地 S3 转存/清理。默认测试中的两个 S3 项为 ignored，必须显式运行；CI 已分别执行，不能把常规测试绿色误认为真实 S3 已测。

```sh
# 先按 M4.1 文档启动隔离 PostgreSQL、MinIO，并注入 fixture 专用变量。
RUST_TEST_THREADS=2 cargo test --locked -- --include-ignored
RUST_TEST_THREADS=2 cargo test --release --locked -- --include-ignored
```

限制的是无关测试用例同时运行数；每个用例内并发准入、worker 抢占、取消竞态仍真实并行，未放宽生产超时或移除故障断言。默认测试并发下观察到旧语义检测 fixture 的短期限失败，当时本机 load average 约 15；相同代码使用 2 个测试线程的 26 项网关回归通过。完整结果应以受控并发重跑证据为准，保留此前失败记录，不把本地测试当作生产容量认证。

真实供应商输出域名/Content-Length/强 ETag/条件请求/TLS/流量成本、生产 S3 权限、密钥轮换、混合版本与恢复窗口登记 LIVE-11。M4.3b 的格式解析、恶意文件/二进制内容检测、真人独立审阅、当前 turn 输出批准和逐块交付撤销检查仍需开发；本包没有将“哈希正确”或“人工批准输入”视作输出合规。
