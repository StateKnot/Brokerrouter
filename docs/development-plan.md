# 开发执行计划

更新：2026-09-24。代码基线：`e01ecb9`。依据 [R0–R5 里程碑](milestones.md) 与 [验收清单](acceptance-backlog.md) 执行，原 M 编号继续表示功能归属。本计划拆成 **25 个开发/验收包**，当前均未关闭；先实施 R0，不能把计划写完视为缺陷已修复。

默认按一个开发主线排程；环境负责人提供 CI、预生产和运维条件，业务验收人确认发布范围及真实使用结果。下文的工作顺序不依赖额外研发人手。暂不承诺日历上线日期：R0 完成后依据实耗和真实环境条件排 R1，后续阶段在入口重新估算，外部等待与开发工时分开记录。

## 执行规则

1. 每包包含实现、针对根因的回归、相关契约/运行文档和验收证据；原则上形成一个可独立审查、可回退的 PR。确需拆分时，前置 PR 不开放未完成的能力，不把“已合并”记为“已验收”。
2. 同一主路径按依赖顺序修改；CI、账号、样本和环境准备可同步进行。前一里程碑未退出，后续里程碑只准备依赖，不继续堆叠新功能。CI 暂不可用时可完成当前 R0 的本地修复和可审查补丁，但不能合并或发布。
3. PostgreSQL、账本、治理 operation、claim/receipt、持久事件及私有资产机制继续复用。只有现有模型无法表达必要事实时才追加迁移，不改写已应用迁移、历史摘要、审批或执行证据。
4. 一个调用是否执行过与结果现在能否释放分别判断；任何审批恢复、策略升级、连接刷新或客户端重试都不能重新执行已发生或受理不确定的副作用。
5. 真实联调按已授权范围、Secret 引用及剩余费用预算执行。fixture 用于可重复故障验证，真实供应商、真实身份/Runtime 和实际部署各自保留证据，不能互相替代。

### R0.3 MCP 输入/输出语义检测驱动（AUD-02）

- 范围：`Edge::call/release`、[Gateway::check](../src/gateway.rs)、[judge.rs](../src/judge.rs)、[mcp_server.rs](../src/mcp_server.rs)、[权限清单](../deploy/permissions.sql) 和现有语义/MCP 测试。
- 复用现有“登记检测 → 执行检测 → 重读当前策略”机制，明确由哪个受信执行身份推进 pending 检测。MCP 公网 edge 不能因此获得模型供应商密钥、审批权限或完整 runtime 数据库权限；权限确需扩展时使用最小服务边界并补实际角色反向测试。
- 输入尚未进入工具队列时也必须可推进检测；输出待释放及已完成重放都能推进新策略检测。重启、请求断开和检查响应丢失保留检测身份，不新建重复收费调用；GET 不触发收费检测，策略连续变化返回可恢复状态而非无限循环。
- 回归：输入/输出各覆盖 pass、risk、非法结果、超时、预算不足、检测执行者崩溃、并发重放、检测期间策略升级；验证状态收敛、失败转审批、单次检测计费、无递归检测，以及未获准前不派发工具/释放输出。
- 交付：受信检测驱动接线、最小权限/部署配置、永久回归和运行说明；通过 AUD-02，并复验 AUD-01。负责人：后端开发。

### R0.5 SSE 连接生命周期与有界内存（AUD-04）

- 范围：[gateway.rs](../src/gateway.rs) 的 `StreamSession/start_stream/consume_stream`、历史结果重放和错误发送，以及 [api.rs](../src/api.rs) 的 `stream_chat`、配置、网关测试和 edge 运行配置。
- 对实时流与重放流统一施加字节预算、帧上限和存活连接额度；连接许可随响应体消费结束、截止时间或断开释放，不能随上游完成提前释放。重放采用按需生成或受控生产，不能在返回 receiver 前等待填满一个无人消费的有界队列。
- 有界队列不能让慢消费者卡住上游读取/计费。发送超时后停止下游交付并释放缓冲，受上游总时限和响应大小限制继续完成结算，或持久化不确定费用；不退款、不回退重发、不提前发送 `[DONE]`。无后续上游事件时，连接截止时间仍须生效。
- 回归/负载：正常流、历史重放、完全不读/极慢读取、上游先结束、突发大帧、连续新增滞留连接、客户端断开和优雅停机；记录实际连接数、队列字节、进程 RSS、结算耗时和账本。
- 测试前在 [运行说明](operations.md) 固定实际目标环境的连接上限 C、每连接缓冲 Q、上游并发 U、响应上限 R、发送/连接/上游时限及 RSS 预算。说明 `C × Q + U × R` 之外的解析、重放、框架/代理缓冲开销；以全进程负载测量验证，不能把队列容量当成总内存上限。超额准入必须可观测且不接收收费请求。
- 交付：有界实现、可重复负载场景、配置值/测量结果及告警阈值；通过 AUD-04。负责人：后端开发 + 环境负责人。
