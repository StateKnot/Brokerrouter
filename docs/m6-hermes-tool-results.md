# Hermes 工具文本结果：隔离、释放与恢复

状态：R1.1 开发中。本文记录工具文本接口和原生宿主边界，不表示二进制产物、真实通道发布或完整生产验收已经通过。

## 执行完成与正文释放

工具输入沿用治理 operation、当前规则、真人审批和一次性 claim。工具已经产生副作用后，适配器先持久化已执行事实及完成回执；回执或响应丢失只能补交同一事实，不能再次执行工具。副作用已发生而最终正文尚未落盘时，恢复返回执行未知或结果不可用，不能重新运行工具或回调来重建正文。

最终文本按原始 UTF-8 字节加密存入 SQLite，绑定原输入 operation、turn、工具、模型绑定、最终参数摘要、内容 SHA-256、字节数和期限。恢复先核对不可变事实及密文；不得用新的结果覆盖原结果。SQLite 使用 WAL、`synchronous=FULL` 和 `0600`，保存期限到达后清除密文，保留执行和摘要证据。

原生工具返回值还可能经过宿主 observation 改写和子目录提示。输出治理检查位于这些核心变换之后，普通工具完成日志、spill 文件、模型历史、会话 flush 和完成回调之前。恢复直接重检已冻结文本，跳过派发和正文加工回调。受管模式不执行尚无安全认证的可发布原文的 Relay/请求/执行 middleware；关闭治理模式保留原宿主行为。此边界不是任意 Python 工具或插件的进程沙箱，工具自身的文件、网络和日志权限仍须单独限制及认证。

## 服务端契约

运行时只使用自己的虚拟 Key，不能携带真人签名私钥或审批决定能力。接口为：

| 请求 | 输入 | 结果 |
| --- | --- | --- |
| `POST /v1/governance/tool-results` | `input_operation_id`、`claim_token`、`evidence_ref`、`text` | 原子记录完成回执与加密正文，返回结果 ID、摘要、字节数和期限，不返回正文 |
| `POST /v1/governance/tool-results/{id}/release` | 严格空 JSON 对象 `{}` | 当前治理结果；只有 `ready` 包含精确正文 |

输入 operation 必须是同租户、同 Key 的已 claim 的具名 `tool_input`。服务端从原 operation 推导 turn、模型与工具身份；客户端不能指定这些授权事实。相同 claim、证据引用和文本重放返回同一结果与期限，变化则冲突。此前已成功登记的同一完成回执可以补交文本，不能补成另一份执行证据。

文本按 JSON 字符串序列化后的大小限制为 512 KiB，包含转义开销；超限拒绝，不截断。客户端的本地冻结上限与此线协议上限分别校验，超限结果保留已经执行事实并停止释放。当前接口仅接受文本，文件路径、二进制字节或产物 metadata 不代表产物已经入库或审核。

释放使用固定 `runtime-result-output:{result_id}` 身份，重检当前用户、Key、Runtime 绑定、turn、模型授权、结果期限、规则版本及审批。语义检测由已有 Gateway 检测执行与账本结算机制驱动；事务不跨供应商网络等待。请求断开后后台仍持有已启动的检测，完成结算。`checking` 只返回检测 ID，`waiting_approval` 只返回审批协议，均无正文。GET 不执行收费检测；普通 checks/claim/receipt API 禁止使用这个输出命名空间。

数据库锁不会阻止审批按壁钟到期。共享 gate 记录本次实际使用的 grant 最早期限，在 gate 写入及调用方最后事务工作后用 PostgreSQL 时钟重新核对；到期返回 `policy_changed` 并回滚，不消费 claim、不完成 MCP 调用，也不返回正文。

服务端同一事务保存不可变摘要、执行证据和密文。到期维护清理结果密文及派生语义输入密文，保留事实，不能重新写回。输出释放不 claim、不登记另一次工具执行，也不延长原期限。

## 仍需完成的 R1 验收

- 二进制产物真实字节进入私有存储、技术扫描、语义审核、审阅和下载授权；不能将文本接口认证推广到产物。
- 固定完整 Hermes 环境的串行、并行、委派、MCP、内联及异步工具矩阵；源码契约测试和两个未运行的完整宿主导入用例分别记录。
- 原生通道会话写入与发布回执的崩溃恢复、持久事件游标、多实例租约与发布去重。
- 真实身份系统、受信通道 ingress、用途分离的服务身份、TLS 和可重建部署；完整原生用户审批与重启续跑。
