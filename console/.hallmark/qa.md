# Console visual and interaction review

Reviewed 2026-09-14. Scope: the actual login, CNY usage and request-log surfaces, not a marketing site. Hallmark supplied Workbench/Cobalt and responsive/interaction checks; ui-styling supplied the Tailwind implementation conventions. Business rules and authorization remain Rust/BFF contracts.

Pre-emit critique: P5 H4 E4 S5 R4 V5. The hierarchy makes CNY cost primary and keeps uncertainty explicit. Mobile is intentionally long-form rather than hiding financial detail. This is the first frontend in the repository, not a recolour of an earlier output. No separate study/DNA diagnosis was made. The optional site-wide Cobalt token file was absent; the documented Cobalt palette and semantic tokens in `tokens.css` were used, with measured contrast adjustments. Chinese glyphs use the declared system CJK fallback; Latin display/body fonts are self-hosted.

## Evidence and limitations

- Final production build: strict CSP without inline scripts/styles, same-origin self-hosted assets.
- 38 Playwright tests (19 each Chromium/WebKit), 12 unit tests. Login keyboard/expiry, failed logout, cross-window logout, permission denial, late responses, schema mismatch, microsecond cursor, exact tiny/large numbers, date bounds/UTC, 31-day narrow graph/table, axes/controls and geometry checks.
- Inspected full-page screenshots from `test-results/` (ignored, not committed). The WebKit vertical native meter was visibly blank despite semantic tests passing; replaced it with an SVG, added positive bar geometry checks, then visually rechecked every required width. Native select height, initial `<dl>` structure, graph width and focus colour were also corrected.
- Browser API fixtures and Nginx upstream fixtures are separate from real Rust DB/HTTP tests; no claim of actual IdP or whole-deployment browser certification. Real MFA, production certificate chains, assistive technology, Firefox and physical devices remain LIVE-14.

Slop review: no unresolved applicable visual gate observed in the reviewed surfaces; no “58/58 automated checks” claim. The implementation and deployment release gates in `docs/acceptance-backlog.md` remain authoritative.
